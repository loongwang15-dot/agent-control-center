# 证据、授权与停止规则

## 状态定义

| 状态 | 含义 |
|---|---|
| `PASS` | 指定范围内有真实、可复核证据，所有关键验收项完成 |
| `PARTIAL` | 部分步骤或平台已通过，但完整交付未完成 |
| `FAIL` | 已执行并观察到明确失败，或结果不符合验收标准 |
| `BLOCKED` | 登录、权限、窗口、工具或外部状态阻断，无法继续当前路径 |
| `NOT RUN` | 本轮未执行该动作，不能推断结果 |
| `UNVERIFIED` | 有声明或间接迹象，但缺少足以确认的当前证据 |

每个状态都绑定范围。例如“即梦首页只读 PASS”不等于“即梦上传 PASS”；“历史闭环 PASS”不等于“当前会话 PASS”。

## 证据强度

从弱到强：

1. Agent 计划或自述；
2. 工具调用成功返回；
3. 页面可访问性快照或窄 DOM 查询；
4. 页面截图；
5. 页面状态发生预期变化；
6. 输入文件/参数在页面中可见；
7. 真实输出资产出现且可打开；
8. 输出已下载，文件格式、尺寸、哈希和内容可核验。

按任务选用足够强的证据。上传至少需要附件 chip、缩略图、文件名或页面读回；生成至少需要真实产出；交付至少需要可访问的最终文件。

## 审批矩阵

| 动作 | 默认 |
|---|---|
| 打开公开页面、列标签、读取标题 | 可执行只读检查 |
| 读取已登录页面结构和当前余额 | 在用户任务范围内可只读检查 |
| 上传用户指定文件 | 记录文件范围；对外可见平台上必要时先确认 |
| 发送聊天/邮件/评论 | 发送前确认内容与目标 |
| 生成、修改、重跑 | 明确代数、预算和参数后授权 |
| 支付、会员、发布、删除、覆盖 | 每次单独明确授权 |
| 第三方 OAuth、验证码、风控 | 用户手工完成 |
| Windows 当前桌面接管 | 当前指令明确授权，可随时停止 |
| 连接已登录 Profile 的 CDP | 单独说明风险并取得授权 |

授权只覆盖当前任务和明确数量，不自动延续到追加生成或下一批任务。

## 记录规则

- 使用绝对路径报告本地最终产物；Skill 内部相对引用只用于包文件。
- 保存任务必需的最小截图和状态，不保存 Extension 状态页完整快照。
- 对可能包含账号、聊天、文件名或个人信息的画面做脱敏或裁切。
- 不记录 Cookie、Token、API Key、认证 URL、浏览器存储或完整请求头。
- 子 Agent 结果先保存为文件再引用；不要只在对话中转述。
- 同一文件记录大小、SHA-256，必要时记录媒体类型、像素尺寸、页数或记录数。

## 费用与幂等

- 提交前记录预计费用和当前余额。
- 只提交一次；点击超时后先确认是否已创建任务，再决定是否重试。
- 自动重试只用于确认幂等的读取或可安全重复的动作。
- 有副作用且状态不确定时标记 `UNVERIFIED`，等待人工检查，不要追加第二次。
- 完成后记录实际费用与授权上限的差异。

## 停止条件

满足任一条件即停止并报告：

- 两次相同失败；
- 认证或连接状态矛盾；
- 页面价格/数量/账号超出授权；
- 可能产生重复扣费或重复发送；
- 需要读取无关敏感信息；
- 下载文件缺失、不可打开或与任务不符；
- 子 Agent 请求越过 `allowed_tools` 或审批动作；
- 当前操作会抢占用户前台且未获桌面接管授权；
- 用户要求暂停、中止或改变目标。

停止不是任务失败的同义词；安全停止后应保留已完成产物、证据和准确恢复入口。
