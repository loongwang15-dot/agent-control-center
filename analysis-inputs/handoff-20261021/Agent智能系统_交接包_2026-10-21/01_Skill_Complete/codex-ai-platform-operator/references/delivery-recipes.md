# 交付类型路由

本参考把常见任务映射到合适的执行面和验收证据。只在当前任务需要时读取对应小节。

## 对话型内容生成

适用于 DeepSeek、WorkBuddy、豆包等现有对话 Agent。

执行前明确：

- 用户指定的入口是网页还是桌面客户端；
- 是否需要登录、长思考或特定模型；
- 是否允许发送非敏感任务内容；
- 期望成品格式和是否需要复制、下载或保存。

验收：

- 保存平台原始回复，不只手写摘要；
- 记录平台/客户端、模型可见名称、开始与完成时间；
- 记录人工介入、提示重试和前台占用；
- 对长文本检查结构完整、关键结论和用户要求；
- 用户指定桌面版时，不能用网页版成功替代。

## 图片、海报与批量视觉生成

适用于 Lovart、即梦等现有平台。

执行前核对平台、项目、参考图、模型、技能、画幅、数量、比例、提示词、显示价格和余额。只提交用户明确授权的批次。

验收：

- 页面出现真实输出，而不是仅有排队或“生成中”；
- 打开预览并确认结果和参数；
- 使用平台下载入口，不复制未授权的临时地址；
- 检查图片可解码、像素尺寸、文件和哈希；
- 平台状态提示与真实资产矛盾时同时记录；
- 默认保留平台标识和水印，不擅自规避；
- 完成后停止，不自动追加变体或重跑。

## 文件上传与参考素材工作流

上传成功的最低证据是页面出现文件名、附件 chip、缩略图、预览或等价读回。File chooser 打开、按钮点击和工具返回成功都不够。

如果点击入口不产生 File chooser：

1. 检查弹窗、遮挡、禁用和加载；
2. 用窄范围只读查询确认控件；
3. 平台明确支持拖放时，可用标准 drag/drop 作为交互路径；
4. 仍失败则在两次同类失败后停止当前路径并报告。

上传后确认目标文件、数量、顺序和是否误带入旧附件。生成前再次核对，避免参考素材混淆。

## 公开网页研究与参考整理

适用于检索设计参考、官方文档、公开页面和竞品资料。

执行原则：

- 官方来源优先于第三方教程；
- 登录墙出现时由用户决定是否登录，不自动提交第三方凭据；
- 可将公开索引页作为发现入口，但引用证据应回到真实公开页面；
- 分别记录“搜索结果缩略图”“公开页面元数据”和“登录后站内内容”；
- 不用缩略图冒充可商用素材，遵守来源和版权边界；
- 建立来源清单时写明日期、链接、用途和核验状态。

验收为可追溯来源、页面真实内容和与研究问题的相关性，不是截图数量。

## 平台连接器与办公数据

适用于 WorkBuddy 钉钉连接器、日历、待办、审批等结构化查询。

验收分为四层：

1. 插件已安装；
2. 插件已启用；
3. 账号授权有效；
4. 实际读取/写入成功。

四层不能互相替代。记录查询时间、账号范围、过滤条件、返回数量和错误码；错误响应不能推导为“没有数据”。涉及发送、修改、审批或创建外部记录时，先展示内容和目标。

## 桌面 Agent 任务

只有用户明确指定桌面客户端或桌面能力不可由网页替代时使用。

优先在独立 VM、Windows Sandbox、第二台设备或远程 Worker 中执行。不要用最小化窗口或 Windows 虚拟桌面冒充隔离，也不要默认复制主设备登录数据。

验收：

- 窗口与应用身份匹配；
- 输入框获得焦点且内容读回正确；
- 只提交一次，确认平台已接收；
- 等待真实完成并从原会话取回完整结果；
- 工具中断后先检查是否已提交，再从原会话恢复；
- 记录是否抢占前台和人工介入。

## Agent 或子任务委派

使用显式 `task.json` / `result.json` 契约。主 Agent 给子 Agent 最小允许工具、审批动作、预算和停止条件；子 Agent 不继承未写明的权限。返回后核验关键证据和产物，不因子 Agent 自称 PASS 就直接接受。

## Skill 创建或修改

任务涉及 Skill 时：

- 目标宿主可用时，先用 `$skill-creator` 约束触发、入口和渐进披露；
- 系统性新建、升级、拆分、迁移或部署时，再用 `$ai-skill-engineering-hub` 的需求台账和验收门；工具不可用时人工保留同等记录；
- 不把完整项目报告打包成 Skill，只提炼可改变未来决策的规则、必要脚本和按需参考；
- 修改既有 Skill 前保存版本或确认已有可恢复包；
- 结构校验、包级一致性、真实行为和目标部署分别报告，不能互相替代。

## 自动化与定时任务

自动化只执行用户明确授权、可幂等或无需授权的动作。涉及登录、验证码、桌面接管、数据共享、支付、发布或新增订阅时停止并通知。状态未变化时保持安静，只有完成、失败或需要用户处理时更新。
