# 项目接续与交接

当工作区存在根 `AGENTS.md`、`agent-memory/`、`prompts/切换前交接指令.md` 或等价文件时，先恢复项目上下文，再执行用户当前任务。这是可选模式；没有这些文件时，不要让本流程阻塞单次平台任务。

## 启动读取

按以下顺序读取，直到足以复述目标、当前状态和下一步：

1. `AGENTS.md`；
2. `agent-memory/00_PROJECT_BRIEF.md`；
3. `agent-memory/01_CURRENT_STATE.md`；
4. `agent-memory/02_DECISIONS.md`；
5. `agent-memory/03_NEXT_ACTION.md`；
6. `agent-memory/04_EVIDENCE_INDEX.md`；
7. `agent-memory/05_HANDOFF_LOG.md`；
8. 当前任务直接依赖的原始报告、配置、脚本和产物。

记忆文件是索引，不是事实的最终证明。至少核对一个与本轮任务相关的原始报告或当前工具状态；历史截图、历史输出和“上次通过”不能直接当成当前可执行能力。

## 接班复述

开始有副作用的执行前，用简短内部或用户可见复述确认：

- 项目最终目标与明确的非目标；
- 当前优先级；
- 已通过、部分通过、失败和阻塞项；
- 用户最近一次授权范围和仍然禁止的动作；
- 本轮第一步及停止条件。

发现记忆与 `AGENTS.md`、原始证据或用户最新指令冲突时，按“用户最新明确要求 → 更具体的项目规则 → 原始证据 → 摘要记忆”的顺序处理，并报告影响了哪一阶段。不要无提示地删除旧资产或把旧结论改成相反结论。

## 任务期间

- 新产生的真实动作使用独立运行目录，不覆盖旧证据。
- 需要修改用户文件、平台内容、账号设置或费用状态时，重新对照当前授权。
- 子 Agent 或外部平台返回状态后，主 Agent 核验实际结果。
- 若任务改变了项目方向、能力边界或长期禁止项，记录为决策；普通执行细节留在运行记录。
- 只更新受影响的记忆章节，不重写整份历史。

## 阶段收尾

### 当前状态

在 `01_CURRENT_STATE.md` 记录：

- 最后核实时间和时区；
- 本轮真实完成、失败、阻塞或未运行的内容；
- 平台、版本、连接和登录态的核实范围；
- 产物绝对路径、关键元数据和证据入口；
- 历史 PASS 与本轮状态的区别。

### 下一步

在 `03_NEXT_ACTION.md` 写出唯一下一步及其前置条件。区分：

- 现在就能做的只读检查；
- 必须先得到授权才能做的动作；
- 需要用户手工完成的登录、验证码或桌面接管；
- 当前工具阻塞下的替代路径。

### 证据索引

更新 `04_EVIDENCE_INDEX.md` 中实际存在的报告、截图、日志和配置。写明每条证据能支持什么、不能支持什么；不要把含有认证信息的页面列入索引。

### 决策与日志

只有会改变未来执行的内容才写入 `02_DECISIONS.md`，例如控制面变化、授权边界、平台故障的新证据或架构优先级。模型切换、阶段完成、重要失败和恢复动作追加到 `05_HANDOFF_LOG.md`。

## 交接最低信息集

交接给另一个模型或 Agent 时，至少包含：

```text
goal:
current_priority:
completed_with_evidence:
partial_or_blocked:
user_authorizations:
forbidden_actions:
last_safe_action:
artifacts:
next_action:
stop_conditions:
```

摘要可以压缩语言，但不能把 `BLOCKED`、`NOT RUN`、`UNVERIFIED` 改写成成功，也不能遗漏费用、登录、前台接管或不可逆操作的限制。

## 禁止模式

- 把整个聊天历史无筛选写入项目目录。
- 只读摘要后就宣称工具或平台当前可用。
- 因一个旧阶段已 PASS 而跳过本轮最小验证。
- 为“保持连续性”复制 Cookie、Token、会话文件或浏览器 Profile。
- 在阶段结束时只回复聊天，不保存真实路径、状态或恢复入口。
