# 在切换模型、压缩上下文、关闭会话前发送给当前 Codex

请将**本轮实际工作状态**交接给下一个模型，不能只总结聊天内容。

1. 读取原始代码、配置、`AGENTS.md` 与项目最新验收文件，区分真实测试证据和口头推断。
2. 更新 `agent-memory/01_CURRENT_STATE.md`：真实已完成、失败/阻塞、当前运行版本、证据来源、最后更新时间。只有已实测 PASS 才可写 PASS。
3. 更新 `agent-memory/03_NEXT_ACTION.md`：写出新模型**第一步具体做什么**、继续操作顺序、停止条件、需要的用户授权。
4. 更新 `agent-memory/04_EVIDENCE_INDEX.md`：填入真实存在的报告、日志、截图及配置路径，不含密钥、Cookie 或 Token。
5. 如有有效的技术选型/目标变化，给 `agent-memory/02_DECISIONS.md` 新增编号决策；在 `agent-memory/05_HANDOFF_LOG.md` 追加一次交接记录。
6. 回答用户：已更新文件清单、当前通过/阻塞项、下一个模型的首要任务。不要告诉新模型从零重新搭建或重复已经通过的验收。

禁止为了生成漂亮的报告而虚构成功；不要将浏览器登录会话信息写入文件。
