# 直接发送给切换后的 Codex 模型

你现在接手的是**已有进度的 Agent Work OS 本地 AI 平台联动项目**，不是新项目。

开始执行前，请按以下顺序进行：

1. 读取项目根目录 `AGENTS.md`，确认其中已经合并“跨模型连续性”片段；如果没有，先提出最小合并方案而不是覆盖原文件。
2. 依次读取 `agent-memory/00_PROJECT_BRIEF.md`、`01_CURRENT_STATE.md`、`02_DECISIONS.md`、`03_NEXT_ACTION.md`、`04_EVIDENCE_INDEX.md`、`05_HANDOFF_LOG.md`。
3. 根据 `04_EVIDENCE_INDEX.md` 在本机寻找**真实原始报告**，重点核对 `P1_CODEX_LOVART_ACCEPTANCE.md` 和 `.codex/config.toml`；没有找到时如实标识“文件未找到”。
4. 先输出不超过 400 字的**接班确认**，至少说明：最终目标、当前唯一主线、已经通过的事项、当前阻塞、下一步最小动作、尚需用户批准的操作。
5. 继续推进 `03_NEXT_ACTION.md` 的当前任务；优先复用现有环境与工具，不重新安装平台、不重新写 UI、不绕去 OpenClaw 验证。
6. 只有真实测试通过才能更新 PASS；任务收尾时同步更新最新状态、证据索引和交接日志。

特别要求：本项目的目标是**Codex 控制现成桌面/网页 AI 平台（Lovart、即梦、豆包、WorkBuddy、DeepSeek）**。不要把“仅用 DeepSeek API 完成聊天”当作跨平台协作成功。未得到用户许可，不要消耗 Lovart/即梦积分。

如果当前模型无法调用原有 MCP 工具，应先报告工具/配置缺口，不能伪装已经操作成功。
