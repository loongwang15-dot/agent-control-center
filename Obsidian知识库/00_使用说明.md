# Agent 知识库

这个文件夹可以在 Obsidian 中通过「打开文件夹作为仓库」打开，也可以从总控台的「Obsidian 知识仓」编辑。

## 建议的工作流程

1. 新资料先进入 `00_收件箱`，保留来源。
2. 项目目标、当前状态和唯一下一步保存在 `10_项目`。
3. 已核验、可复用的方法和结论保存在 `20_知识`。
4. Skill 的说明与使用入口保存在 `30_Skill索引`，原始 Skill 独立维护。
5. 成果说明与交付清单保存在 `40_成果`。
6. 失效或已被替代的版本转入 `90_归档`，说明被什么替代。

每篇笔记建议保留 `project`、`source`、`status`、`tags` 和 `updated` 属性。自动整理结果先标为草稿，核验后再改为已核验。

## 图片

图片保存在 `attachments` 中，可从总控台上传后插入，也可在 Obsidian 粘贴。支持的本地预览格式为 PNG、JPEG、GIF、WebP。图片自动识别与 OCR 尚未配置，当前可用文字说明帮助检索。

## 更新与检索

当前总控台支持 Markdown 关键词检索。Agent 的 VaultSearch / VaultRead 工具读取同一套资料；VaultWrite 更新已有笔记时检查版本，发生冲突会拒绝覆盖。

通过总控台保存的旧版本在仓库外的 `runtime/vault-history` 留存；在 Obsidian 或其他编辑器直接修改的历史，需要另行配置 Git、Obsidian 文件恢复或备份。

本说明是新平台的使用指南；历史验收报告不能直接当作本机此刻的平台连接状态。
