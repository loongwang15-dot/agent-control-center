# Agent 智能系统

## 长期目标

建设统一的 Agent 总控台，管理任务、已接入的 Agent、Skill、知识、进度和成果。复用已有平台的真实能力，并支持不同模型根据同一份项目状态继续工作。

## 当前建设范围

- 基于 AgentScope 2.0 官方源码的本地服务与界面。
- SQLite 保存 Agent、会话和配置记录。
- Obsidian 本地 Markdown 知识仓、关键词检索、图片附件及版本冲突检查。
- 本地单用户使用。

## 待验收能力

- 模型凭据配置与一次真实 Agent 推理。
- Codex、Lovart、即梦、DeepSeek、WorkBuddy 等执行器在本机的实际接入。
- 多模型切换后真实任务接续。
- 图片 OCR、语义检索及自动知识整理流程。

## 下一步

在总控台配置一个有权使用的模型，通过知识工具读取本页并返回依据来源的答复。模型请求成功后，再逐个验证外部 Agent 适配器。

当前部署的最终验证结果以项目根目录的部署验收记录为准。
